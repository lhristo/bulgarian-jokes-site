# Смях на български

Public website: https://lhristo.github.io/bulgarian-jokes-site/

Generated public website files and published jokes only. No database, credentials, withheld candidates, or administration endpoints.

Joke source: https://ritnikotkata.com/license . Attribution–NonCommercial 4.0: https://creativecommons.org/licenses/by-nc/4.0/ . Each joke retains source and licence links. Formatting is normalized; wording is not translated or rewritten. Keep this collection noncommercial.

Updates are collected and published daily by a private GitHub Actions workflow at 06:17 UTC, independently of the owner’s Mac. Scheduled runs may be delayed. Existing jokes are never replaced; days without accepted new candidates keep the collection intact.
